# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

A two-part app (`backend/` Python FastAPI, `frontend/` React + Vite) with two tools in one dashboard:

- **Post assistant** — makes Marathi festival / event / news-reaction / custom social posters for a politician client. Text is generated by AI, the poster is composed by code, and the client approves drafts before use.
- **Story Studio** (served at `/studio`) — a staged story-development workflow (idea → concept → characters → … → story → Fountain screenplay) where the writer approves each stage.

`backend/README.md` is **outdated**: it describes an earlier Streamlit version (`streamlit run app.py`, `pages/`). The app is now FastAPI + React; ignore those parts.

## Commands

Backend (run from `backend/`; a `venv` exists there):
```bash
python -m venv venv && venv\Scripts\activate      # Windows
pip install -r requirements.txt                    # note: requirements.txt is UTF-16 encoded
playwright install chromium                        # headless browser that renders posters to PNG
python setup_assets.py                             # creates folders, downloads Marathi fonts
uvicorn api.main:app --reload --port 8000
```

Frontend (run from `frontend/`):
```bash
npm install
npm run dev        # Vite on :5173, proxies /api and /files to :8000
npm run build      # outputs frontend/dist, which the FastAPI app serves itself
npm run lint       # oxlint
```

There is no test suite in the repo (story code mentions tests replacing `story.llm.complete`, but no test files exist).

## Configuration

- `backend/.env` holds secrets/config: `GEMINI_API_KEY`, `OPENAI_API_KEY` (background images), and DB settings (`DATABASE_URL` or `DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASSWORD` — PostgreSQL). Optional: `GEMINI_MODEL`, `STORY_MODEL`, `STORY_MAX_TOKENS`, `IMAGE_MODEL`, `IMAGE_QUALITY`, `STUDIO_ACCESS_KEY` (protects `/studio`).
- `backend/config.py` has per-client settings (name, designation, accent colour, logo/footer paths, `style_examples` of real past Marathi captions grouped by post type, poster `SIZES`, `SHOW_AI_LABEL`).

## Architecture

**Backend (`backend/`)**
- `api/main.py` only builds the app and mounts routers; each endpoint category is its own file in `api/routes/` (festivals, events, reactions, custom_posts, month_plan, plans, drafts, templates, designs, clients, studio, status). It also serves `/files/output`, `/files/assets`, and the built React app (`frontend/dist`) with a catch-all, and returns a clear 404 for unknown `/api/*` routes.
- **Multi-client**: `api/middleware.py` reads the `X-Client-Id` header into `storage.clients.set_current(...)`; storage modules scope data by that current client. The frontend sends this header (see `frontend/src/api/request.js`).
- `storage/` — SQLAlchemy models/engine in `db.py` (Postgres), plus per-concern modules (drafts, festivals, templates, fonts, categories, languages, plans, clients). `data/` holds legacy CSV/JSON.
- `posts/` — logic per post type (`festival/`, `event/`, `reaction/`, `custom/`, plus template-based posts and `rewrite.py`). Rules: AI paints only the background; text, leader photo and logo are added by code; solemn days (punyatithi) get a muted poster and no "शुभेच्छा"; news posts take facts only from the article, numbers are verified by code, political topics are blocked.
- `ai/claude.py` — despite its name, this is the **Gemini** client (name kept so imports don't change). `ai/image_gen.py` calls OpenAI for backgrounds.
- `design/` — poster rendering: HTML templates in `design/templates/` rendered to PNG via Playwright (`poster.py`, `frame.py`, `finish.py`, `hd_export.py`), template filling, PPTX→Fabric conversion (`pptx_to_fabric.py`), Google/custom font handling.
- `story/` — Story Studio: `engine.py` (stage workflow; each approved stage is canon, carried in the "Story Bible" `bible.py`), `prompts.py`, `validation.py`/`checks.py` (continuity), `fountain.py` (screenplay export), `store.py` (persistence), `llm.py` (the single place that calls the model), and `jobs.py` (long steps run in a background thread with progress; one step per project; the UI polls; running jobs are marked failed on restart via the startup hook in `main.py`).
- Stray `*.txt` copies of source files (e.g. `main.py.txt`, `template_ai.py.txt`) are backups, not code.

**Frontend (`frontend/`)**
- Two Vite entries: `index.html` → `src/main.jsx` (client pages: Dashboard, CreatePost, EventPage, Reaction, Festivals, Approvals, History, Templates, Clients, Editor) and `studio.html` → `src/studio/main.jsx` (Story Studio, with its own `api.js`, `useStudio.jsx`, CSS). Both are built together.
- `src/api/*.js` are thin per-resource wrappers over `request.js`; `src/editor/` + `fabric` power the poster canvas editor.
